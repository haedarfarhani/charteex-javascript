Overview & Product Philosophy

SmartChart is an open-source, framework-agnostic charting library engineered from the ground up for modern JavaScript and TypeScript. Built with a zero runtime dependency architecture, it delivers high-performance vector SVG and hardware-accelerated Canvas rendering without requiring D3, Chart.js, or external date helpers.

TypeScript Native Zero Runtime Dependencies Dual Renderer (SVG / Canvas) Financial & Technical Indicators Accessible ARIA Support 100% Tree-Shakable

Quick Start

import { createChart } from '@smart-chart/core';

const chart = createChart('#chart', {
  type: 'line',
  data: {
    series: [
      { name: 'Revenue', data: [{ x: 1, y: 100 }, { x: 2, y: 140 }, { x: 3, y: 220 }] }
    ]
  },
  theme: 'dark',
  renderer: 'auto',
  animation: { enabled: true, duration: 600 }
});

chart.render();

Technical Indicators API

Independently testable technical analysis calculation algorithms:

import {
  calculateSMA,
  calculateEMA,
  calculateWMA,
  calculateRSI,
  calculateMACD,
  calculateBollingerBands,
  calculateVWAP
} from '@smart-chart/core';

// Calculate 20-period Moving Average
const sma = calculateSMA(closePrices, 20);

// Calculate 14-period Relative Strength Index
const rsi = calculateRSI(closePrices, 14);

// Calculate Bollinger Bands
const { upper, middle, lower } = calculateBollingerBands(closePrices, 20, 2);
