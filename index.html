Charteex Design System Architecture

Charteex decouples visual tokens from rendering calculations. Themes provide semantic colors (background, text, axis, grid, tooltip, series, semantic), typography scales, spacing, radius, and shadows.

Beautiful by Default Design Tokens Interactive Legends RTL Aware Accessible ARIA Dual Renderer

Custom Theme Creation

import { createChart, createTheme, extendTheme } from 'charteex-javascript';

// 1. Extend an existing theme
const myDarkTheme = extendTheme('midnight', {
  primary: '#8b5cf6',
  seriesColors: ['#8b5cf6', '#10b981', '#f59e0b']
});

// 2. Or create a custom theme from scratch
const brandTheme = createTheme({
  name: 'corporate',
  tokens: {
    colors: {
      series: ['#0284c7', '#0d9488', '#d97706']
    },
    radius: { md: 10 }
  }
});

const chart = createChart('#chart', {
  type: 'line',
  theme: brandTheme,
  data: { /* ... */ }
});
chart.render();
